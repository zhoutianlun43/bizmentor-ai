# BizMentor 文档总目录（docs/）

> 所有文档均为双版本：`.md`（文件查看）+ `.html`（双击浏览器打开）。
> 配合 `outputs/README.md`（阶段报告索引）与 `BizMentor-Portable-完整知识包.zip`（便携完整包）使用。

## 📌 核心文档（4 份，最重要）

| 文档 | 内容 | 什么时候读 |
| --- | --- | --- |
| **BizMentor-Master.md / .html** | 完整项目圣经：架构/数据模型/AI/研究/决策/记忆/知识/Agent/Skill/产品/部署/规范/阶段史/未完成 | **任何 AI / 任何人接手，第一个读它** |
| **bizmentor-manifest.json** | 机器可读清单：模块/关键文件/表/路由/环境变量/命令 | AI 程序化索引 |
| **BizMentor-System-State.md / .html** | 当前状态 + 开发规则 + 最近 Phase 记录（唯一事实来源） | 每次开发前后同步 |
| **BizMentor-Asset-Inventory.md / .html** | 所有资产位置：代码/部署/数据库/环境变量/存储地图/风险 | 找东西时读 |

## 🧭 阅读顺序（新 AI 接手）

```
1. BizMentor-Master.md      → 完完整整了解项目
2. BizMentor-System-State.md → 当前状态 + 规则
3. bizmentor-manifest.json  → 机器清单（可选）
4. BizMentor-Asset-Inventory.md → 资产在哪
5. outputs/README.md        → 按需翻历史报告
```
